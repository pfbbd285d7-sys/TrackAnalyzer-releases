# TrackAnalyzer — анализ и реконструкция треков

Created by Oleg Frolov · PROFFIT

## Версия 1.5.20

Резервные копии теперь сохраняются рядом с SBIN в папке backup. Первая сохранённая версия отмечается original. Прежние копии и история восстановления копируются при открытии файла с проверкой целостности; старое хранилище сохраняется для отката.

• Уменьшен объём обновления: программа, среда исполнения и деморолик загружаются раздельно. Неизменные ресурсы повторно не скачиваются.
• Исправлена обработка пересекающихся аномалий и использование соседних файлов.
• Устранены повторная привязка дорожных опор и связанные лишние заезды.
• Исправлено сохранение исходных участков возле стоянок и обработка замкнутых маршрутов.
• Улучшено определение источника пробега и подтверждённой перевозки автомобиля. Исходные CAN-сообщения сохраняются.
• Собственный расчётный и серверный код поставляется скомпилированным; устаревшие программные файлы удаляются при обновлении с сохранением пользовательских данных.
• Повышена устойчивость обновления и отката Windows при кратковременной блокировке файлов.
• Улучшена диагностика ошибок подготовки дорожного графа.

В сложных участках с недостаточными координатами реконструкция может оставаться приближённой и не объяснять весь измеренный пробег. Два таких обращения остаются открытыми; выпуск не означает восстановления их точного маршрута. Причина одного обращения об импорте графа пока не воспроизведена.

## Установка на Mac

[Скачать компактный установщик Mac](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/download/mac-1.5.20-b2026102202/TrackAnalyzer-Mac-Installer.dmg)

Mac с Apple Silicon, macOS 13 или новее. Откройте DMG и запустите установщик. Для первой установки выберите новую папку. Программа, карта и подготовленный граф будут загружены в неё автоматически. Аккаунт GitHub не нужен.

Установщик занимает около 2,2 МБ. Объём первой загрузки показывается после выбора компонентов; подготовьте не менее 8 ГБ свободного места для загрузки и распаковки. Папка остаётся переносимой. На Intel Mac эта сборка не работает.

Сборка пока без Apple Developer ID и нотариализации Apple: macOS может потребовать штатное подтверждение открытия. Подпись списка пакетов и контрольные суммы проверяются установщиком.

## Установка на Windows

[Скачать компактный установщик Windows](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/download/windows-1.5.20-b2026102202/TrackAnalyzer-Windows-Setup.exe)

Windows 10/11 x64; на Windows 11 ARM64 используется штатная совместимость x64. Установщик около 11 МБ; объём первой загрузки показывается после выбора компонентов. Выберите новую папку; программа и общие с Mac карты/граф будут загружены автоматически. Подготовьте не менее 8 ГБ свободного места. Аккаунт GitHub и отдельная установка Python/Java не нужны. Для интерфейса нужен Microsoft Edge WebView2 Runtime.

Лицензия на компьютер обязательна. Существующая активация Windows сохраняется при обновлении и откате. Подписи Authenticode пока нет: Windows может показать неизвестного издателя. Подпись списка пакетов и SHA-256 проверяются установщиком.

## Обновления

При каждом запуске программа проверяет наличие обновления. Если оно доступно, появляется окно с номером версии, кратким списком изменений, размером загрузки и кнопками «Обновить» и «Позже». Сбой сети не мешает работе. Обновление использует папку запущенной программы, сохраняет данные, самостоятельно закрывает приложение и запускает его после установки. При прерывании загрузка продолжается с проверкой целостности. Для возврата доступен откат предыдущего обновления.

Если в Windows 1.5.12 окно обновления обрезано при увеличенном масштабе экрана, используйте новый установщик Windows и выберите существующую папку программы. Встроенное окно исправлено в Windows-сборке 1.5.13 b2026101907.

При переходе со старых сборок без этого механизма закройте программу, скачайте новый установщик и выберите существующую папку установки. Не создавайте вторую установку в другой папке вместо обновления.

Приложение, среда исполнения, деморолик, карты и графы обновляются раздельно. Пользовательские SBIN, настройки и резервные копии сохраняются. Если пользователь самостоятельно обновил карты или расширил граф через «Хранилище», совместимое обновление приложения сохраняет эти локальные данные.
