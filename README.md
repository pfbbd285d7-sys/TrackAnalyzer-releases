## Установка на Mac

[Скачать компактный установщик Mac](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/download/mac-1.5.11-b2026101802/TrackAnalyzer-Mac-Installer.zip)

Mac с Apple Silicon, macOS 13 или новее. Распакуйте ZIP и откройте установщик. Для первой установки выберите новую папку. Программа, карта и подготовленный граф будут загружены в неё автоматически. Аккаунт GitHub не нужен.

Установщик занимает около 1,9 МБ. Первая загрузка — около 1,85 ГБ; подготовьте не менее 8 ГБ свободного места для загрузки и распаковки. Папка остаётся переносимой. На Intel Mac эта сборка не работает.

Сборка пока без Apple Developer ID и нотариализации Apple: macOS может потребовать штатное подтверждение открытия. Подпись списка пакетов и контрольные суммы проверяются установщиком.

## Обновления

Программа проверяет обновления ежедневно. В меню TrackAnalyzer доступна команда «Проверить обновления…». Сбой сети не мешает работе. Установка выполняется только после завершения обработки и закрытия приложения. При прерывании загрузка продолжается с проверкой целостности. Для возврата доступен откат предыдущего обновления.

Приложение, карты и графы обновляются раздельно. Пользовательские SBIN, настройки и резервные копии сохраняются. Если пользователь самостоятельно обновил карты или расширил граф через «Хранилище», совместимое обновление приложения сохраняет эти локальные данные.

[Общий пакет данных](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/tag/data-20261018-01) один для Mac и Windows. Части `.part` загружает установщик; открывать их вручную не требуется. Пакет содержит Россию и Хэйлунцзян (Китай). Отсутствующие территории можно подготовить через «Хранилище» программы.

Windows-установщик будет добавлен отдельным выпуском после проверки. Опубликованные данные уже общие для обеих платформ.
