## Версия 1.5.14

Ускорена обработка файлов. Окно обновления сохраняет стабильный масштаб и удобно отображает описание.

## Установка на Mac

[Скачать компактный установщик Mac](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/download/mac-1.5.14-b2026102001/TrackAnalyzer-Mac-Installer.zip)

Mac с Apple Silicon, macOS 13 или новее. Распакуйте ZIP и откройте установщик. Для первой установки выберите новую папку. Программа, карта и подготовленный граф будут загружены в неё автоматически. Аккаунт GitHub не нужен.

Установщик занимает около 1,9 МБ. Первая загрузка — около 1,85 ГБ; подготовьте не менее 8 ГБ свободного места для загрузки и распаковки. Папка остаётся переносимой. На Intel Mac эта сборка не работает.

Сборка пока без Apple Developer ID и нотариализации Apple: macOS может потребовать штатное подтверждение открытия. Подпись списка пакетов и контрольные суммы проверяются установщиком.

## Установка на Windows

[Скачать компактный установщик Windows](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/download/windows-1.5.14-b2026102001/TrackAnalyzer-Windows-Setup.exe)

Windows 10/11 x64; на Windows 11 ARM64 используется штатная совместимость x64. Установщик около 11 МБ, первая загрузка около 1,85 ГБ. Выберите новую папку; программа и общие с Mac карты/граф будут загружены автоматически. Подготовьте не менее 8 ГБ свободного места. Аккаунт GitHub и отдельная установка Python/Java не нужны. Для интерфейса нужен Microsoft Edge WebView2 Runtime.

Лицензия на компьютер обязательна. Существующая активация Windows сохраняется при обновлении и откате. В 1.5.13 улучшены распознавание пробега, обработка времени, восстановление сложных участков и использование соседних файлов. Подписи Authenticode пока нет: Windows может показать неизвестного издателя. Подпись списка пакетов и SHA-256 проверяются установщиком.

## Обновления

При каждом запуске программа проверяет наличие обновления. Если оно доступно, появляется окно с номером версии, кратким списком изменений, размером загрузки и кнопками «Обновить» и «Позже». Сбой сети не мешает работе. Обновление использует папку запущенной программы, сохраняет данные, самостоятельно закрывает приложение и запускает его после установки. При прерывании загрузка продолжается с проверкой целостности. Для возврата доступен откат предыдущего обновления.

Если в Windows 1.5.12 окно обновления обрезано при увеличенном масштабе экрана, используйте новый установщик Windows и выберите существующую папку программы. Встроенное окно исправлено в Windows-сборке 1.5.13 b2026101907.

При переходе со старых сборок без этого механизма закройте программу, скачайте новый установщик и выберите существующую папку установки. Не создавайте вторую установку в другой папке вместо обновления.

Приложение, карты и графы обновляются раздельно. Пользовательские SBIN, настройки и резервные копии сохраняются. Если пользователь самостоятельно обновил карты или расширил граф через «Хранилище», совместимое обновление приложения сохраняет эти локальные данные.
