Известное ограничение: в отдельных файлах повторное открытие или повторное исправление может вновь обнаруживать эпизоды и изменять ранее записанный результат. Эта версия не объявляет устранённым весь класс таких случаев. Исходные резервные копии сохраняются.

## Установка на Mac

[Скачать компактный установщик Mac](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/download/mac-1.5.29-b2026110501/TrackAnalyzer-Mac-Installer.dmg)

Mac с Apple Silicon, macOS 13 или новее. Откройте DMG и запустите установщик. Для первой установки выберите новую папку. Программа, карта и подготовленный граф будут загружены в неё автоматически. Аккаунт GitHub не нужен.

Установщик занимает около 2,2 МБ. Объём первой загрузки показывается после выбора компонентов; подготовьте не менее 15 ГБ свободного места для загрузки и распаковки. Папка остаётся переносимой. На Intel Mac эта сборка не работает.

Сборка пока без Apple Developer ID и нотариализации Apple: macOS может потребовать штатное подтверждение открытия. Подпись списка пакетов и контрольные суммы проверяются установщиком.

## Установка на Windows

[Скачать компактный установщик Windows](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/download/windows-1.5.29-b2026110501/TrackAnalyzer-Windows-Setup.exe)

Windows 10/11 x64; на Windows 11 ARM64 используется штатная совместимость x64. Установщик около 11 МБ; объём первой загрузки показывается после выбора компонентов. Выберите новую папку; программа и общие с Mac карты/граф будут загружены автоматически. Подготовьте не менее 15 ГБ свободного места. Аккаунт GitHub и отдельная установка Python/Java не нужны. Для интерфейса нужен Microsoft Edge WebView2 Runtime.

Лицензия на компьютер обязательна. Существующая активация Windows сохраняется при обновлении и откате. Подписи Authenticode пока нет: Windows может показать неизвестного издателя. Подпись списка пакетов и SHA-256 проверяются установщиком.

## Обновления

При каждом запуске программа проверяет наличие обновления. Если оно доступно, появляется окно с номером версии, кратким списком изменений, размером загрузки и кнопками «Обновить» и «Позже». Сбой сети не мешает работе. Обновление использует папку запущенной программы, сохраняет данные, самостоятельно закрывает приложение и запускает его после установки. При прерывании загрузка продолжается с проверкой целостности. Для возврата доступен откат предыдущего обновления.

Если в Windows 1.5.12 окно обновления обрезано при увеличенном масштабе экрана, используйте новый установщик Windows и выберите существующую папку программы. Встроенное окно исправлено в Windows-сборке 1.5.13 b2026101907.

При переходе со старых сборок без этого механизма закройте программу, скачайте новый установщик и выберите существующую папку установки. Не создавайте вторую установку в другой папке вместо обновления.

Приложение, среда исполнения, деморолик, карты и графы обновляются раздельно. Пользовательские SBIN, настройки и резервные копии сохраняются. Если пользователь самостоятельно обновил карты или расширил граф через «Хранилище», совместимое обновление приложения сохраняет эти локальные данные.

## Общие карты и графы

[Единый дорожный граф](https://github.com/pfbbd285d7-sys/TrackAnalyzer-releases/releases/tag/data-20261023-osm20261022) один для Mac и Windows и включает Россию, Украину, Казахстан, Беларусь, Монголию, Китай, Грузию и Турцию. Размер загрузки графа — около 2,93 ГБ, после распаковки — 6,29 ГБ. При переходе с прежнего комплекта это однократная загрузка; дальнейшие обновления программы не скачивают неизменённый граф повторно.

Граф поставляется готовым. Его удалённые файлы можно восстановить через установщик; для добавления страны вне комплекта обратитесь к разработчику. Части `.part` загружает установщик — открывать их вручную не требуется. Подробная карта OpenStreetMap загружается автоматически при увеличении масштаба и сохраняется для повторного использования.

Карты © OpenStreetMap contributors, ODbL 1.0. Источники Geofabrik; атрибуция и лицензии приложены к выпуску данных. Данные предназначены для анализа записанных треков, не для текущей навигации.

Обе платформы используют одинаковые версии и ссылки на общий пакет данных; отдельные каналы обновлений не мешают друг другу.

Доступность GitHub зависит от сети пользователя; работоспособность у всех российских провайдеров не гарантируется.

Реконструкция остаётся вероятностной. При недостатке данных сохраняется указание низкой достоверности; оно не означает подтверждения точного пути или места стоянки. Для ранее неверно исправленного файла может потребоваться восстановление исходной копии и повторная обработка.

Известные ограничения: в отдельных сложных файлах могут сохраняться прямые соединения или ошибочные фрагменты. Их дальнейший разбор, а также изменение служебного кода качества GPS при повторном открытии, перенесены в следующую версию.
